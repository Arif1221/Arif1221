# Profile README setup

1. Replace the root `README.md` in `Arif1221/Arif1221` with this one.
2. Upload the `assets/` folder, preserving `assets/listening-card.gif`.
3. Upload `.github/workflows/snake.yml` to the same path in the repository.
4. In the repository, open **Settings → Actions → General → Workflow permissions** and allow the workflow to have read and write permissions for repository contents.
5. Open **Actions → Generate contribution animation → Run workflow** once. The workflow publishes the animated contribution snake to the `output` branch; after the first successful run it refreshes daily.

The README uses third-party hosted widgets for typing text, GitHub statistics, language distribution, skill icons, and the profile-view counter. Those services are external and may occasionally be rate-limited or unavailable. The music card is an animated visual link to the track featured on your portfolio; it does not claim to show live Spotify playback.
